# Legends of IdleOn — как устроена игра и что делать с русификацией

Анализ Steam-билда **26123052** (`app.asar` из `resources/`, оригинал сохранён как `app.asar1`).

## 1. Устройство клиента

```
LegendsOfIdleon.exe            Electron
resources/app.asar             архив Electron (формат ASAR)
  src/main/*.js                обёртка Electron + Steam (greenworks)
  distBuild/static/game/
    N.js          ~25 МБ       ВЕСЬ код игры + ВСЕ игровые тексты (Haxe/Stencyl → JS, минифицировано в 1 строку)
    lib/default.pak ~45 МБ     ассеты: "lime-asset-pack" + склеенные gzip-блоки
    assets/sfx, assets/music   звуки (лежат отдельно)
resources/app.asar.unpacked/   нативный модуль greenworks (не трогаем)
```

* Движок — **Stencyl** (Haxe + OpenFL/Lime). Индекс `default.pak` (путь → позиция/длина) зашит в `N.js`
  в виде Haxe-сериализованной строки (`Bd.parse('{"name":null,"assets":"aoy8:position...`).
* В `default.pak` ~18 400 файлов:
  * `assets/data/*.png` (~17 000) — UI-картинки по именам (`UIquickref1.png`, `playerselect4.png`…), **многие с вшитым английским текстом**;
  * `assets/graphics/1x/font-N.fnt/.png` — **94 растровых шрифта** (AngelCode XML). Кириллицы нет ни в одном;
  * `sprite-*`, `background-*` — спрайты/фоны.
* Пробел в игровых текстах — `_`, перенос строки в описаниях — `|`, `@` — разрыв абзаца в диалогах,
  `{` / `}` — подстановка числа.

Инструменты в репозитории:

```bash
python tools/asar.py extract app.asar1 work/orig          # распаковка ASAR
python tools/pak.py extract N.js default.pak work/pak       # распаковка ассетов по именам
```

## 2. Встроенная локализация игры

В игре **уже есть своя система переводов**, на ней и стоит строить русификацию.

| Что | Где |
|---|---|
| Выбор языка | `OptionsListAccount[153]`, значения 1..7 = 🇺🇸 🇬🇧 🇫🇷 🇩🇪 🇰🇷 🇯🇵 🇨🇳 (1-2 = английский) |
| Индекс языка | `m._customBlock_Language()` = `[153]-3` → `-1` EN, `0` FR, `1` DE, `2` KO, `3` JA, `4` ZH |
| Шрифт для CJK | `m._customBlock_LANGUAGEfont()` → font 616/621/622 (только для `Language()>=2`) |
| Иконки флагов | **глифы шрифта 106**: `"p"` — кнопка «Language», `"q"` — панель из 7 флагов, `"r"`/`"s"` — рамка выбора |
| Клик по флагу | экран создания персонажа: `IsXYmouseWithinBounds(382,690,480,530)`, ширина флага 44px, `Math.min(7, …)`; экран логина: x 154..327, шаг 25px |
| Переключение «на лету» | после клика игра сама пересобирает `ItemDefinitionsGET` и т.д. из `*LANG`-списков |

Списки переводов (каждый — массив `[EN, FR, DE, KO, JA, ZH]`, элемент `Language()+1`):

* `scripts.LanguageLists2` (`fd.*`): `ItemNamesLANG` (1423 предмета), `MobNamesLANG` (266), `ClassNamesLANG`,
  `RandostuffLANG`, `PlayerInfoStatsLANG`, `GemshopEtcLANG`, `gemshopDescLANG`, `CompanionDefLANG`,
  `CardBonusDesc`, `SkillInfoDesc`, `EquipmentBonusMISC`
* `scripts.LanguageLists` (`Gh.*`): `TalentNamesLANG`, `TalentDescLANG`, `LangMapName`
* `scripts.LanguageLists3` (`di.*`): `BubbleLANG`, `VialsLANG`, `AlchemyShopsLANG`
* Диалоги NPC (включая тексты квестов): `CustomMaps.NPCdialogue0..4` = FR / DE / KO / JA / ZH
  (`scripts.LanguageNPClist*`), ключ — имя NPC, выбирается как `"NPCdialogue"+Language()`.

Перевод предмета применяется к его `displayName` — поэтому **название предмета в квесте, в инвентаре и
в помощнике квестов совпадает автоматически**, если переводить через `ItemNamesLANG`, а не по месту отрисовки.

Ограничения нативной системы:
* `Language()` вызывается в 409 местах; 98 проверок вида `2<=Language()` включают CJK-логику
  (смена шрифта на иероглифический и т.п.). Для русского (индекс 5) их нужно аккуратно исключить.
* Покрыта в основном старая часть игры (W1–W3). Многие строки новых миров и UI захардкожены
  прямо в `drawString("…")` или лежат в обычных `CustomLists` без LANG-версий.

## 3. Разбор существующего русификатора (Steam guide 3800560343)

Что делает:

* Подменяет `N.js` **целиком** (25 → 47 МБ): ~18.5 МБ «прелюдии» + оригинальный код с **5067 вставками**
  (`__idleonRUDrawSite__` ×4319 — обёртка почти каждого `drawString`).
* Перевод на лету при отрисовке: словарь 34 783 точных строк + 8 851 + 9 578 regex-шаблонов,
  плюс сотни точечных хаков вёрстки (наковальня, питомцы, магазины, AFK…).
* Добавляет ~450 ассетов в `default.pak`: шрифты `font-30xxx/42xxx/48xxx/50xxx` с кириллицей и
  257 перерисованных UI-картинок.
* Переключатель «РУССКИЙ · ON/OFF» хранит состояние в `localStorage.IdleOnRUEnabled`.
* Оставлен отладочный «инспектор»: каждые 0.7–1.2 с шлёт запросы на `http://127.0.0.1:17843`.

Почему всё плохо:

1. **Ломается при каждом обновлении игры.** `N.js` заменён полностью, мод собран под конкретный билд
   (в конце файла `IDLEON_RU_SOURCE_V1 … "buildid":"26123052"`). Любой патч Lavaflame2 → нужен новый
   `N.js` от автора, иначе игра запускается со старым кодом и ломается/рассинхронизируется с сервером.
2. **Шрифты.** Кириллица дорисована отдельно и в другом стиле: строчные буквы мельче и «плавают» по
   высоте, прыгает базовая линия, огромные межбуквенные интервалы, `Ё` съезжает. В оригинальных шрифтах
   IdleOn строчные = заглавные (капитель), для кириллицы надо так же.
3. **Картинки «мыльные».** Текст на них отмасштабирован с интерполяцией: в `UIquickref1.png` было
   18 цветов, стало 992 — антиалиасинг на пиксель-арте.
4. **Перевод машинный.** Путаются род и падежи («Лучшая еда, которую я **ел**… я не **хранила**… пока
   ты это **делала**», «очистите 1 **запасов**», «поддельную **бутылку** … настоящей **банку**»).
5. **Рассинхрон названий.** Перевод идёт по тексту на экране, а не по данным, поэтому один и тот же
   предмет может называться по-разному в квесте и в инвентаре; в квест-листе часть строк вообще
   остаётся английской (QUESTS IN PROGRESS, Difficulty, Waves Completed…).
6. Тяжёлый рантайм: regex-перебор при отрисовке, постоянные XHR на localhost.

Что из этого «легко пофиксить»: шрифты и картинки можно переделать с нуля, переключатель — хорошая
идея. А вот архитектуру (полная копия `N.js` + тысячи вставок) починить нельзя: её проще не наследовать.

## 4. Предлагаемая архитектура

**Принцип: патчер, а не копия.** Репозиторий хранит переводы, ассеты и набор патчей с якорями-регулярками.
Сборщик берёт `app.asar` текущей версии игры и сам применяет патчи. Обновилась игра → перезапускаем сборку,
чиним только те якоря, которые сдвинулись.

1. **Русский как 8-й язык в родной системе.**
   * В панель флагов (глиф `q` шрифта 106) добавляется 🇷🇺 в том же стиле, `Math.min(7,…)` → 8, плюс рамка выбора.
   * Во все `*LANG`-массивы дописывается 7-й элемент (RU), в `CustomMaps` — `NPCdialogue5`.
   * CJK-проверки `2<=Language()` ограничиваются диапазоном KO/JA/ZH.
   * Выбор русского храним **локально** (как у мода, в `localStorage`), а в облачное сохранение пишем
     английский — иначе веб/мобильная версия без мода получит `[153]=8` и может упасть.
2. **Быстрый переключатель** EN⇄RU (идея автора мода хорошая): кнопка вызывает тот же код переинициализации,
   что и клик по флагу, — удобно для тестов и сравнения.
3. **Шрифты.** Генератор кириллицы для каждого из 94 шрифтов из его же латиницы:
   совпадающие буквы копируются (А В Е К М Н О Р С Т Х), часть получается отражением/сборкой
   (И Я Г П Л Д Ж Ш Щ Ц Ч Ь Ы Ъ Б Э Ю Ф Й Ё), затем к маске применяются обводка/тень этого шрифта.
   Сложные буквы — ручная правка в PNG-оверрайдах. Строчные = заглавные, как в оригинале.
4. **Тексты, которых нет в LANG-списках** — один лёгкий хук на точное совпадение строки
   (хэш-таблица, без regex) в одной точке отрисовки, а не 4000 вставок.
5. **Картинки с текстом** — перерисовка пиксельным шрифтом без масштабирования, с палитрой оригинала;
   длинные слова сокращаем, а не сжимаем.
6. **Перевод** — в редактируемых файлах (JSON/таблица: ключ, EN, RU, комментарий) + глоссарий
   (предметы, мобы, NPC, локации), чтобы названия совпадали везде. Шутки и сленг адаптируем; если
   каламбур не переводится — делаем свой или оставляем смысл.

## 5. Объём

* Мод содержит ~34.8 тыс. точных строк (почти каждая продублирована в вариантах `_` и пробел → ~17 тыс.
  уникальных) — это ориентир объёма текста игры.
* Нативные LANG-списки: ~1.4 тыс. предметов, ~270 мобов, ~680 талантов с описаниями, ~200 пузырей/фиалов,
  диалоги ~всех NPC.
